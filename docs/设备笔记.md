# 设备笔记 · Kindle Paperwhite 3

## 硬件

| 项 | 值 |
| --- | --- |
| 机型 | Kindle Paperwhite 3 |
| 系统 | `Linux kindle 3.0.35-lab126 armv7l`（固件 2023-08 构建） |
| 屏幕 | 1072 × 1448，16 级灰度（`eips` 只能画 1-bit 或 16 灰） |
| WiFi MAC | 在 `data/config.env` 里设 `KINDLE_MAC=xx:xx:xx:xx:xx:xx`（Amazon Technologies 前缀，**唯一可靠标识**） |
| IP | 不固定：DHCP 会漂，按 MAC 定位（`bin/kindle_ip.py` 自动查找） |

## 关键路径

| 路径 | 说明 |
| --- | --- |
| `/mnt/us/kindle-dash/dash.sh` | 看板主循环（轮播、触摸翻页、电源键退出、夜间放睡） |
| `/mnt/us/kindle-dash/launch.sh` | 启动器（杀旧进程、恢复原生状态栏、启动 dash.sh） |
| `/mnt/us/usbnet/` | 越狱的 SSH 环境 |
| `/mnt/us/usbnet/auto` | 开机自启触发文件（存在则 volumd 起来后自动开 SSH） |
| `/tmp/dash.sh` | 运行中的副本（launch.sh 每次从 `/mnt/us` 拷贝过来） |
| `/dev/input/event1` | 触摸；`event0` 是电源键 |

## 常用命令

```sh
# 重启看板
sh /mnt/us/kindle-dash/launch.sh

# 恢复原生状态栏（时间 + 电池）
lipc-set-prop com.lab126.pillow displayChrome 1

# 读电量
lipc-get-prop com.lab126.powerd battLevel

# 截取真实屏幕内容（8bpp，行宽 1088）
dd if=/dev/fb0 bs=1088 count=1448 > /tmp/fb.raw

# 看板日志
tail -f /tmp/dash_loop.log
```

## 夜间放睡

`dash.sh` 里 `NIGHT_START=2100`、`NIGHT_END=900`：21:00 主动挂起，
用 RTC 定 09:00 唤醒。**深睡时 RTC 唤醒不可靠**，经常要等到用户碰设备才真正醒——
这段期间看板不刷新属于正常，不是故障。

## 已知限制

- `eips -k file` 存的不是可读画面（16bpp 原始数据），验证屏幕要用 `dd /dev/fb0`
- 深睡时 WiFi 挂起，SSH/ping 全超时，只能在设备醒着时远程操作
- 中文文件名在 dropbear 下 `ls` 显示为 `?`（shell 无 UTF-8 locale），但文件本身正常
- 推书到 `documents/` 后需触发扫描才进书库；PDF 需 90×122mm 才适配屏幕
