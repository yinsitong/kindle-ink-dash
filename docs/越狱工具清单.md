# 越狱与设备环境：上游工具清单

本项目**不包含**任何 Kindle 越狱工具、Amazon 官方固件或更新包。
下面的工具全部来自社区上游，请从各自官方发布页下载。

> 为什么不在仓库里放二进制：
> ① `Update_*.bin` 含 Amazon 签名，再分发有版权风险；
> ② 工具链 69MB，占仓库体积绝大部分，且与本项目代码无关；
> ③ 上游会持续更新，仓库内快照很快过期。

## 前置条件

| 项 | 要求 |
| --- | --- |
| 机型 | Kindle Paperwhite 3（其他型号见 [kindlemodding.org](https://kindlemodding.org/) 的兼容表） |
| 固件 | **≤ 5.16.2.1.1**。PW3 的最终固件就是 5.16.2.1.1，不会再更新，正好落在可越狱范围 |
| 电脑 | Windows / macOS / Linux 均可 |
| Amazon 账号 | 需注册（中国大陆注册的账号可能访问不到商店，可切换到美亚/日亚） |

> 动手前先开飞行模式，并删除 Kindle 根目录下所有 `.bin` 文件，
> 避免越狱过程中被 OTA 更新覆盖。

## 按顺序安装

### 1. 越狱（取得 root）

- **WinterBreak** — <https://github.com/KindleModding/WinterBreak>
  固件 ≤ 5.16.2.1.1 用这个。利用商店缓存漏洞，把特制页面塞进 `.active_content_sandbox`。
- **WinterBreak2** — <https://github.com/KindleModding/Winterbreak2>
  Mesquito 出问题时的替代方案，要求固件 < 5.16.4。
- 固件 5.18.1 及以上：改用 AdBreak（见 kindlemodding.org 的向导）。

### 2. 装 Hotfix（防止越狱被固件更新冲掉）

- **Hotfix** — <https://github.com/KindleModding/Hotfix>
  下载 `*_hotfix_universal.bin` 放设备根目录，`设置 → 设备选项 → 更新您的 Kindle`。
  重启后点一次「Run Hotfix」。**每次固件更新后要再点一次。**

### 3. 装 KUAL（图形启动器，可选但推荐）

- **PEKI** — <https://github.com/KindleTweaks/PEKI>
  解压后把 `KUAL.sh`、`KUAL.jar` 放进 `documents/`。

> 实测：PW3 + 5.16.2.1.1 上 KUAL 菜单能显示扩展但 action 不执行。
> 本项目的设备端脚本**不依赖 KUAL**，走 scriptlet / 直接执行更可靠。

### 4. 装 MRPI（包安装器，装 USBNetwork 要用）

- **MRPI（现代机型）** — <https://kindlemodding.org/jailbreaking/Legacy/post-jailbreak/installing-kual-mrpi/>
  解压后把 `extensions/`、`mrpackages/` 放到设备根目录。安装时占约 220MB 空间，先腾出余量。

### 5. 装 USBNetwork（提供 SSH / dropbear）

- **USBNetwork 0.22.N** — MobileRead 帖 225030
  <https://www.mobileread.com/forums/showthread.php?t=225030>
  取 `Update_usbnet_0.22.N_install_pw2_and_up.bin` 放进 `mrpackages/`，
  然后 KUAL → Helper → Install MR Packages。

### 6. 配置 SSH（只用 WiFi）

`/mnt/us/usbnet/etc/config`：

```text
USE_WIFI="true"
USE_WIFI_SSHD_ONLY="true"
```

公钥追加到 `/mnt/us/usbnet/etc/authorized_keys`（一行一个）。
**位置必须是这里**——rootfs 只读，dropbear 不读 `~/.ssh/`。

开机自启：把 `usbnet/DISABLED_auto` 改名为 `usbnet/auto`
（本项目的 `bin/watchdog.py` 会自动补登记）。

### 7. 部署看板脚本

把 `device/dash.sh`、`device/launch.sh` 推到 `/mnt/us/kindle-dash/`，
具体命令见[完整教程](./Kindle魔改看板-完整教程.md)。

## 风险与边界

- 越狱会使保修失效，操作失误可能导致设备变砖。请先备份 `/mnt/us` 下的个人文件。
- 越狱工具与固件版本强绑定。升级固件前先确认对应版本的越狱方案仍然存在。
- 本文档只做导航，不提供任何 Amazon 固件或签名文件。
