# 时间线补录 · 新会话提示词

> 用途：需要批量补录时间数据、或调整「时间去哪了」页面时，把这个模板粘给 AI 助手。

```text
帮我给 Kindle 墨水屏看板的「时间去哪了」页面补录时间数据。

背景：有一台越狱 Kindle PW3 跑四页轮播看板，第四页是时间线页
（自动采集 Mac 前台应用 + 手动补录）。项目结构与渲染链路见仓库 README。

手动补录方式：往 data/timelog/YYYY-MM-DD.manual.tsv 追加一行，
格式为「HH:MM-HH:MM<TAB>描述」（tab 分隔，手动段会覆盖同分钟的自动段），
然后运行 python3 render/render_timeline.py 重渲染，约 5 分钟内上屏。

要补录的内容：
1. 【在这里写时间段和描述，如：16:23-17:26 需求沟通（开会）】
2. ……
```

## 备注

- 单条临时备注不必开会话：直接在终端追加一行 `.manual.tsv` 再跑一次渲染即可
- 分类规则在 `render/render_timeline.py` 的 `CATEGORIES` 与 `categorize_manual()`，
  按自己的习惯改词表就行
